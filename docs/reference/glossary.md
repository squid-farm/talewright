# Glossary

These terms describe references to factions, items and story values in Talemark.

| Term | Definition |
|---|---|
| reference | A name for a story thing, such as `item:lantern`. |
| property | A value of a referenced thing, written after its id, such as `faction:guild:standing`. |
| faction | A group in the story. `faction:guild` displays its name. |
| standing | The player's numeric standing with a faction, written `faction:guild:standing`. |
| tier | The named band for a faction's standing, written `faction:guild:tier`. |
| item | A thing a character can hold. `item:rope` displays its name. |
| flag | An on/off story value, such as `flag:door-open`; a flag reference is the value itself. |
| variable | A named number or text value, such as `var:coins`; a variable reference is the value itself. |
