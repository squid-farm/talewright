# Author guide

Everything you need to write in **Talemark**, then test and share your story with Talewright.
Talemark is the story-authoring language in your `.tale` files. No programming required.

1. **[Getting started](getting-started.md):** play in your browser and choose the simple no-install path or optional desktop tools.
2. **[Your first story](first-story.md):** build a small, complete story step by step.
3. **[Writing stories](writing-stories.md):** characters, stats, items, factions, skill checks, hubs and conditional text.
   **[Organizing your story](organizing-your-story.md):** start with two files, then split things up when you need to.
4. **[Playing and saving](playing-and-saving.md):** what your players see and can do.
5. **[Testing your story](testing-your-story.md):** check for mistakes and jump straight to any scene.
6. **[Sharing your story](sharing-your-story.md):** send a story file to friends, or make a website or desktop game.
7. **[Troubleshooting](troubleshooting.md):** common problems and fixes.

The [Talemark syntax reference](../reference/talemark-syntax.md) has quick examples first and the full language details after.
Use [error codes](../reference/diagnostics.md) when a check reports a problem; start with the first error.
