# ADR 0005: MPL-2.0

**Status:** Accepted. Under review: see PLAN.md §9, open question 5 (GPL-3.0 plus a linking exception is being
considered).

**Decision:** MPL-2.0 (file-level copyleft). Games built with Talewright can use any license, including commercial ones. Modifications to Talewright's own source files must be shared.
